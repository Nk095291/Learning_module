# What is Azure DevOps

Azure DevOps is a cloud-based platform that provides integrated tools for software development teams. It includes everything you need to plan work, collaborate on code, build applications, test functionality, and deploy to production.

## Core Services : 

- Azure Boards : like jira 
- Azure Repo   : like github
- Azure Pipeline : like circleCI or any CI/CD pipeline
- Azure Test plans : test planning, manual testing and reporting
- Azure Artifacts  : for managing packages.


Typical workflow:

Plan work items in Azure Boards
Code features in Azure Repos with pull requests
Build and package with Azure Pipelines and Azure Artifacts
Test manually and automatically using Azure Test Plans
Deploy through Azure Pipelines to various environments
Monitor progress and metrics through Dashboards
Iterate based on feedback and new requirements
