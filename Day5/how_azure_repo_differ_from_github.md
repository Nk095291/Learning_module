# Azure Repo Vs Github 

Hierarchy: GitHub is User/Org → Repo. Azure DevOps is Organization → Project → many Repos. A project also holds its Boards, Pipelines, and so on.
Integration: Boards, Pipelines, and Repos share one project, so commits and PRs link natively to work items. On GitHub, this is done with Issues and Projects.
version control : In azure we have TFVC and Git , but in github we just have Git. using TFVC you can even restrict access to folders and files.
