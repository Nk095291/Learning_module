# Reflection on Language Change

Most of the things in TypeScript were similar to JS itself, but it puts more emphasis on data structuring and explicitly defining the types of data.

I already had some experience with frontend, so the code structure and syntax were not completely new to me. However, I did learn more about TypeScript by going through the documentation, specially around interfaces, type definitions, decorators and why was it needed.

Overall, the transition was fairly comfortable because of my existing JS experience, but the documentation helped me understand how TypeScript adds type safety and better structure on top of JS.
